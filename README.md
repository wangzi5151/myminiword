# 我的迷你世界 VoxelCraft 2.0

一款使用 Java + OpenGL ES 2.0 编写的 Android 体素沙盒游戏。世界由多层程序化地形、十多种生物群系、洞穴矿脉、河流海岸、六座主题城市、高架地铁、村民与可编辑方块组成，支持生存式挖掘/放置、游泳、飞行、矿车、背包合成，以及实时阴影、泛光、动态天气与水下效果。

- 包名：`com.wangzi5151.myminiword`
- 最低系统：Android 8.0（API 26）
- 目标 SDK：34
- 渲染：OpenGL ES 2.0

## 2.0 主要更新

### 地形（精细化）
- **分层地貌**：大陆架 → 丘陵 → 山脊三层噪声叠加，域扭曲（domain warp）打散噪声团块，海岸线自然弯曲。
- **13 种生物群系**：海洋、沙滩、平原、森林、白桦林、针叶林、雪原、沙漠、稀树草原、丛林、沼泽、山地、雪峰；由温度/湿度场 + 海拔共同决定，边界随气候平滑过渡，地图远端更冷。
- **河流与海岸**：独立河谷噪声下切河床，水面与海平面衔接；浅滩自动铺沙、深水铺砾石/黏土，寒带水面结冰。
- **洞穴系统**：双 3D 噪声“蠕虫”隧道 + 大空腔，只在表层 4 格以下开凿，避免地表塌陷。
- **矿脉**：煤矿、铁矿、金矿、钻石矿用随机游走生成连通矿脉，而非离散噪点；深处还有花岗岩/玄武岩地层。
- **植被**：橡树、白桦、云杉（锥形层叠）、丛林巨树（含垂叶）、金合欢（平顶）、棕榈、沼泽树、仙人掌；花丛按低频“草甸场”成片分布，蕨类出现在丛林与沼泽。
- **跨区块结构**：树木按所属区块生成，并向相邻区块裁剪写入，树冠跨区块不会出现半棵树。
- 巨石、苔石堆、小型遗迹（苔砖墙 + 萤石）随机点缀。

### 城市（精细化）
- **真实路网**：每 20 格一条 5 格宽柏油大道，两侧 1 格混凝土人行道；路口有斑马线，车道有虚线，井盖/减速带等细节。
- **功能分区**：市中心（玻璃幕墙塔楼、退台、屋顶设备/水塔/天线/屋顶花园）、商业区（店面、雨棚、招牌、橱窗）、住宅区（独栋/联排、门廊、阳台、烟囱、围栏院子、花园、车道）、郊区（农田、小屋、绿篱）。
- **六套主题地标**：
  - 中式：双层大殿、金顶、朱柱、宫灯、城墙与角楼
  - 欧式：双塔大教堂、玫瑰窗、尖顶、扶壁
  - 日式：五重塔、鸟居、石灯笼、禅意庭院
  - 阿拉伯：穹顶清真寺、双宣礼塔、拱廊庭院、市集摊位
  - 现代：玻璃超高层、观景平台、尖塔、直升机坪预留
  - 北欧：钟楼市政厅、陡坡屋顶、彩色木屋
- **车站**：高架站台、玻璃幕墙、十字天窗、四角塔楼、站台黄线、长椅、时钟与南侧大台阶。
- **公园**：池塘、石桥、凉亭、环形步道、花坛、长椅与树阵。
- **街头细节**：车道边随机停靠的汽车（车身/车窗/保险杠）、塔楼逐层楼板与电梯井、屋顶设备与供水箱。
- **广场**：喷泉、环形花带、路灯、长椅与四个市集摊位。
- **地形整平**：城市中心整平，外圈 16 格平滑过渡到自然地形，不再出现“悬崖城市”。
- **选址自适应**：六座城市会在地形中寻找平坦陆地（螺旋搜索 ±160 格）后落位，避免城市泡在海里；地图与小地图自动使用新位置。
- **高架地铁**：铁轨沿大道上方架设，钢柱支撑，进城不切割建筑。

### 玩法与表现
- **动态天气**：晴 / 小雨 / 降雪 / 雷雨，自动按气候切换或手动锁定；雨丝、雪花、雷闪、阴天雾效与云层浓度联动。
- **水下**：镜头入水自动切换深蓝雾、压缩视距，并显示水下提示；水中可游泳（减速、浮力、下潜）。
- **HUD**：小地图（城市半径环）、坐标、海拔、生物群系、时刻、天气、最近城市距离、FPS/区块/三角面。
- **粒子**：破坏方块颜色直接取自纹理平均色，奔跑扬尘、入水水花。
- **镜头**：冲刺轻微拉大 FOV、入水收窄 FOV，雨天雾距收拢；寒带云杉树冠会积雪。
- **夜间灯光**：萤石/灯具使用增强顶点亮度，夜里形成灯光点。
- **存档更完整**：除了方块编辑，现在还会保存玩家位置/朝向、飞行状态、快捷栏、背包、时间、天气与画质设置。
- **更多方块**（20 种）：沥青、混凝土、瓦片、深色玻璃、钢材、树篱、红花、黄花、高草、仙人掌、花岗岩、玄武岩、陶土、石板瓦、灯具、泥浆、苔砖、蕨类、云杉叶、丛林叶。

### 性能优化
- **网格构建零跨表查询**：一次性读取 3×3 区块数组构建 18×66×18 邻域，替代 ~19k 次 `ConcurrentHashMap` 查询。
- **线程本地复用**：邻域缓冲、贪心 mask、顶点/索引缓冲全部按线程复用，大幅降低 GC。
- **顶点分配优化**：贪心面生成不再为每个角点分配临时数组。
- **查表**：不透明/固体/液体/植物/硬度使用静态查找表。
- **贪心网格 + 顶点 AO**：不透明方块按同材质合并，透明方块逐面生成；单 part 超 65535 顶点自动拆分。
- **工作站数自适应**：按 CPU 核心数 2–4 条区块线程。
- **水面下移** 0.875 格，水面与岸边衔接更自然。

## 构建

需要 JDK 17、Android SDK（`compileSdk 34`）和可用的 `aapt2`。

```bash
export ANDROID_HOME=/path/to/android-sdk
bash gradlew assembleDebug
```

Termux / 非标准 SDK 环境可使用 aapt2 覆盖参数：

```bash
export ANDROID_HOME=/data/data/com.termux/files/home/android-sdk
bash gradlew assembleDebug \
  -Pandroid.aapt2FromMavenOverride=/data/data/com.termux/files/usr/bin/aapt2
```

运行 JVM 单元测试：

```bash
bash gradlew testDebugUnitTest
```

Debug APK 输出在 `app/build/outputs/apk/debug/`。

## 操作

- 左侧摇杆：前后左右移动（推到底冲刺）。
- 右侧屏幕拖动：转动视角。
- “跳跃”：跳跃 / 飞行上升 / 水中上浮。
- “挖掘”：长按破坏准星指向的方块。
- “放置”：把当前快捷栏方块放到准星指向的位置。
- “飞行 / 行走”：切换飞行模式。
- “矿车 / 下车”：在铁轨附近骑乘或离开矿车；到站可选择停靠。
- 底部快捷栏：16 格方块快速切换。
- “背包”：查看全部方块、选择并按配方合成（18 条配方）。
- “设置”：视距、灵敏度、云层、性能面板、时间流动、实时阴影、画质增强、天气（自动/手动+类型）、时间预设、重置世界。

## 实现概览

| 模块 | 说明 |
| --- | --- |
| `world/TerrainGenerator` | 大陆/丘陵/山脊/河流/气候噪声，洞穴、矿脉、地层与水面填充 |
| `world/Biome` | 群系表（地表/填充方块、树种、密度、植物密度）与选择规则 |
| `world/Decoration` | 跨区块树木、花丛草甸、巨石、遗迹 |
| `world/CityGenerator` | 选址、整平、路网、分区建筑、地标、公园广场、城墙、郊区、车站、铁轨 |
| `world/ChunkMesh` | 贪心网格 + AO、植物十字面片、水面下移、线程本地缓冲 |
| `world/World` | 区块流式加载/卸载、网格任务、编辑存档、射线检测、群系与高度查询 |
| `engine/Weather` | 天气状态机 + 雨雪顶点生成 |
| `GameRenderer` | 阴影/泛光/天空/云层/粒子/天气/水下、存档与 HUD 数据 |

## 测试

`app/src/test` 下的 JVM 单元测试覆盖：

- `ChunkMesh`：超大透明网格拆分安全性、索引边界、普通方块/矿车/村民网格结构。
- `World.raycast`：命中实体方块、面朝向、最大距离、穿水等非实体方块。
- `World` 存档：异步保存等待、文件魔数与条目、编辑写入后重新加载。
- `TerrainGenerator`：高度范围、确定性、群系多样性、水/洞穴/矿脉/植被存在性、生成顺序无关。
- `CityGenerator`：选址在陆地上、车站站台与铁轨存在、道路/人行道/建筑/玻璃/路灯、广场喷泉、地形整平、新方块注册。

```bash
bash gradlew testDebugUnitTest
```

## 已知限制

- 只有 Android 客户端，无桌面或 iOS 版本。
- 单 part 仍使用 `GL_UNSIGNED_SHORT` 索引；超出 65535 顶点时通过多 part / 多 draw call 拆分，未使用 VAO 或索引扩展。
- 存档只记录玩家编辑过的方块，地形本身仍由种子重新生成（换版本后旧存档的地形会变）。
- 没有动态光源传播，夜间灯光使用顶点亮度近似。
- 暂停时最多等待 5 秒让存档完成；极端 I/O 卡顿下可能超时。
- 测试为 JVM 层逻辑测试，不包含 OpenGL 渲染、音频和触控 UI 的仪器测试。
- 世界为无限生成，长时间远距离探索后浮点精度和内存占用会逐渐增加。
